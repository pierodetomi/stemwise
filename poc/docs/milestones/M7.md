### Common setup

The plan assumes the recommended options (a) of Q-66 → Q-72 in [DECISIONS.md](../DECISIONS.md); if the author chooses
others, the steps indicated in parentheses change. No new dependency: only `numpy`, `pyloudnorm` (already used for ANA-1),
`soundfile` (via `audio_io`), `pydantic` and `secrets` from the standard library.

- **Flow of `ab`**: choice of the files (Q-66: `baseline.wav` and `mix.wav` of the plan of `best.json` of the latest run or
  of `--run`, plus optional `--manual <file>`) → reading with `audio_io` (formats of D-011, project frequency, mono
  duplicated) → silence at the end up to the longest (Q-67) → integrated loudness of each and gain toward the weakest,
  attenuations only (Q-68) → permutation with a recorded seed (Q-69) → `ab/A.wav`, `B.wav`, `C.wav` at 24 bit and
  `ab_key.json` next to the folder (Q-70) → measurements on the re-read files, written in the key.
- **Modules**: `ab.py` new, with the pure core on arrays (`prepare`, `match_loudness`, `assign_names`) and the `AbKey`
  model; `runs.ab_run` remains the only point that writes files; selection of the mix reused from `master.select_mix`
  (same rule, D-073), moved where needed without changing its behavior; `cli.py` remains thin.
- **Blinding of the pairing**: the CLI prints the folder, the file names, the common loudness and the path of the key,
  never the origin next to the letter; the warnings (silence added, duration mismatch) name the origin, never the letter.
  Warning at the end: "do not open the key before voting".
- **Determinism**: the audio content of each file depends only on the inputs; the seed decides only which name receives
  which file. The same seed gives the same key.
- **PoC outcome** (criterion of PRD §9): listening sheet `docs/listening.md` (Q-71) filled in by the author; the agent
  derives H1–H5 from the run files and the sheet with the rules of Q-72 and fills in "PoC outcome" in the README, with
  the notes for the product (D-048, D-077). This part is done after the protocol, so **after** the technical close (see
  "Steps").

### Anticipated doubts

- **Equal loudness is not equal "density".** A manual mix run through the limiter, at equal LUFS, sounds fuller than a mix
  without master: for a fair comparison it is best to export it without processing on the master bus (note in Q-3).
- **Silence at the end as a clue.** If the manual mix is shorter, the file with silence at the end is recognizable. The
  damage is small (it only says which one is the manual); if needed, the export is cut to the same duration.
- **Low level.** With Q-68 (a) everything drops to the weakest (the AI mixes sit around −20/−21 LUFS): just raise the
  listening volume, the same for all files.
- **H2 with 3 tracks.** With the rules of Q-72 (a) a track that converges immediately counts as a success; with (b) it
  could make H2 fail without the loop having erred. The decision is the author's.
- **Flagged out of scope — keep out.** No player or listening interface, no command to reveal the key or compute the
  hypotheses, no master in the comparison, no automatic time alignment of the manual mix.
